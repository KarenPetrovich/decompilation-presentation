# Декомпиляция: конец авторского права?

Интерактивная одностраничная презентация на русском языке. Проект состоит из обычных HTML, CSS и JavaScript и не требует сборки или платных сервисов.

## Быстрый запуск в Windows 11

Самый простой вариант — открыть `index.html` двойным щелчком.

Для корректной работы всех встроенных материалов рекомендуется локальный сервер:

```powershell
py -m http.server 8000
```

После запуска откройте [http://localhost:8000](http://localhost:8000).

Если команда `py` недоступна, но установлен Python:

```powershell
python -m http.server 8000
```

## Структура

- `index.html` — содержание, источники, изображения и встроенные видео;
- `styles.css` — визуальный стиль, адаптивность и анимации;
- `script.js` — прогресс чтения, управление движением и окно источников;
- `RESEARCH_AND_CONCEPT.md` — исследование, фактчекинг и сценарная концепция.

## Медиа

Настоящие изображения находятся в `assets/images`, а два MP4 с Mario × Elden Ring и ArkWeb — в `assets/video`. Все материалы воспроизводятся локально и не требуют подключения к интернету.

Интернет нужен только при переходе по ссылкам на исходные проекты и источники.

## Редактирование

Все русские тексты находятся непосредственно в `index.html`. Цвета, шрифты и основные размеры собраны в CSS-переменных в начале `styles.css`. Ссылки на проекты и источники находятся в соответствующих карточках и в секции `#sources`.

## Публикация в будущем

Проект уже совместим с GitHub Pages: используются только относительные локальные пути и статические файлы. Публикация не выполнялась.
